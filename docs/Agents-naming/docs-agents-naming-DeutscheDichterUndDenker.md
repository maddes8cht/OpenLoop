# Docs Agents — Naming

These are the naming proposals for the documentation agents (equivalent to the test authoring agents).

While the test writers draw their names from different mythologies (mainly Greek and Arabic), the naming theme for the docs writers is:

***Deutsche Dichter und Denker*** (*German Poets and Thinkers* — the german phrase behind the cliché *"land of poets and thinkers"*)

## The winners

| Role                      | Name          | Rationale                                                                                                                                                     |
| -------------------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Prep / Analysis**        | **Lessing**   | The born critic and clarifier. He exposes contradictions and gaps and asks the right questions before anything is written.                                      |
| **Writer / Author**        | **Schiller**  | Strong formal power, clarity and a sense of inner order. Writes in a structured, ambitious way — ideal for documentation.                                      |
| **Auditor / Reviewer**     | **Humboldt**  | Systematic thinker and linguist. Checks for accuracy, completeness, internal consistency and lasting order. Excellent as an auditor.                            |
| **Final / Final Gate**     | **Nietzsche** | Incorruptible, sharp eye. Asks the radical questions and decides whether the documentation truly holds up or is only appearance.                                |

## Alternatives

### Alternative, somewhat sharper variant (was in the running)

If you want the auditor to be more critical and style-conscious:

- **Lessing** (Prep)
- **Schiller** (Writer)
- **Heine** (Auditor) – sharp observer, stylistically extremely alert
- **Nietzsche** (Final)

### Or the mixed variant you hinted at

- Lessing (Prep)
- Heine (Writer)
- Humboldt (Auditor)
- Nietzsche (Final)
